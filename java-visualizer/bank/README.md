# מאגר התרגילים

כל שאלה היא קובץ JSON בתיקייה של הנושא שלה (`loops/`, `arrays/`, `strings/`, `classes/`, `recursion/`, `stack/`, `queue/`, `list/`, `tree/`).
לפני שהיא נכנסת לתוסף היא נבדקת: `sh tools/test/bank-check.sh`.

## רמות קושי

| רמה | מה זה | דוגמאות |
|---|---|---|
| **קל** (`easy`) | מעבר אחד על המבנה, ספירה / סכום / מינימום / חיפוש, בלי ליצור מבנה חדש | הערך הקטן ביותר במערך; כמה חוליות גדולות מ-x; סכום מחסנית (והיא חוזרת להיות כמו בהתחלה) |
| **בינוני** (`medium`) | בונים מבנה חדש או משנים את המבנה, או משלבים שתי פעולות | שרשרת חדשה עם כל הזוגיים; תור חדש בסדר הפוך; הוצאת כל המופעים של x ממחסנית; מיזוג שני מערכים ממוינים |
| **קשה** (`hard`) | ברמת שאלת בגרות: כמה סעיפים שנשענים זה על זה, מבנה בתוך מבנה, מחלקה + פעולה חיצונית, ניתוח סיבוכיות | שאלות בגרות מלאות |

## הניסוח

כמו בבגרות: "כתוב פעולה ששמה ..., המקבלת ... ומחזירה ...", דוגמה עם התוצאה, ולמבנים — "בסיום הפעולה ... צריך להיות כמו בהתחלה" כשצריך.
לכל שאלה: נוסח (`question`), ציורים של המבנים (`figures`), והתרגיל (`exercise`) — פעולה לכל סעיף עם הצעה לפתרון, `mainCode` שמריץ את כל הסעיפים ומדפיס,
ו-`expectedOutput` — בדיוק מה ש-main מדפיס כשהכול פתור (הבדיקה מריצה ומשווה).
