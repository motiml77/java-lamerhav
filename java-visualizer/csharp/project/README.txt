תיקיית התרגילים (C#) — מבני נתונים עם הרצה ויזואלית
=====================================================

התיקייה הזאת הוכנה אוטומטית בהתקנה.

  DataStructures-CS.sln   פותחים ב-Visual Studio (או ב-Rider / VS Code)
  Exercise/               התרגיל שלכם (Program.cs) — כותבים את הפעולה במקום ה-TODO
  Examples/               דוגמאות פתורות: מחסנית, תור, רשימה, עץ, מערך, תלמיד, מכונית, רקורסיה
  lib/                    הספרייה Unit4.CollectionsLib.dll (Stack, Queue, Node, BinNode, Student, Car)

הרצה ויזואלית
-------------
Visual Studio:  ליד כפתור ההפעלה הירוק בוחרים "הרצה ויזואלית" (במקום "הרצה רגילה"), ולוחצים עליו.
VS Code:        הסמל "מבני נתונים" בסרגל הצד ← "הרצה ויזואלית" (או הכפתור בפינה של קובץ ה-.cs).
Rider:          Settings ← Tools ← External Tools: Program = %LOCALAPPDATA%\DSViz\cs\dsviz-cs.exe ,
                Arguments = "$ProjectFileDir$" .
שורת פקודה:    %LOCALAPPDATA%\DSViz\cs\dsviz-cs.exe <תיקיית הפרויקט>

"הרצה רגילה" (F5 / Ctrl+F5) מריצה את התוכנית כרגיל, בקונסול, בלי החלון הוויזואלי.

יש כמה פרויקטים בפתרון: מגדירים ב-Visual Studio את הפרויקט שרוצים להריץ
(לחיצה ימנית על הפרויקט ← Set as Startup Project).
