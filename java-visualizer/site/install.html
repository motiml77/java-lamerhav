התקנה

ב-Windows קובץ אחד, ב-Mac שורה אחת. ההתקנה מוצאת לבד את סביבות הפיתוח שבמחשב ומתקינה בכל אחת. בכל סביבה כתוב כאן מה קורה לבד ומה, אם בכלל, נשאר לכם לעשות.

מתחילים

הכפתור מתאים למחשב שאתם גולשים ממנו. האפשרות השנייה תמיד מתחתיו.

הורדה ל-Windows DSViz-Setup.exe · 84 MB

ב-Mac מדביקים את השורה הזו ב-Terminal:

curl -fsSL https://raw.githubusercontent.com/motiml77/java-lamerhav/master/java-visualizer/installer/mac/install.sh | bash

יש לכם Mac? שורת ההתקנה ל-Terminal. יש לכם Windows? הורדת DSViz-Setup.exe.

הקישורים קבועים: אותו קישור מוריד תמיד את הגרסה האחרונה (גם הקיצור is.gd/dsjava). Java 21 כלולה בהתקנה, ולא צריך להתקין שום דבר לפני.

Windows קובץ אחד לכל הסביבות

  1. מורידים את DSViz-Setup.exe ומריצים אותו. לא צריך הרשאות מנהל.
  2. אם מופיע "Windows protected your PC": לוחצים More info ואז Run anyway. הקובץ עוד לא חתום דיגיטלית.
  3. בוחרים באיזו שפה לומדים: Java, C# או שתיהן. C# מסומן מראש כשיש במחשב Visual Studio או Rider.
  4. פותחים מחדש את הסביבה. ב-Eclipse מופיע התפריט "מבני נתונים", וב-VS Code הסמל "מבני נתונים" בסרגל הצד.

לבד מה ההתקנה עושה

  • מתקינה Java 21 (בתוך תיקיית ההתקנה, לא נוגעת ב-Java אחרת)
  • מוצאת כל Eclipse בכל הכוננים ומתקינה בו את התוסף
  • מתקינה את התוסף ב-VS Code, VS Code Insiders, VSCodium ו-Cursor
  • מתקינה את התוסף בכל IntelliJ IDEA (2024.2 ומעלה)
  • ב-C#: Visual Studio, Rider ו-dotnet מכירים את הספרייה בכל פרויקט
  • יוצרת תיקיית תרגילים במסמכים (עבודה קיימת לא נדרסת)
  • מתעדכנת לבד, ברקע

פעם אחת מה עושים אתם

  • מאשרים את האזהרה של Windows (More info, Run anyway)
  • בוחרים שפה ולוחצים "הבא"
  • אם Eclipse או IntelliJ פתוחים, ההתקנה מציעה לסגור אותם

במעבדה: DSViz-Setup.exe /S מתקין בשקט, ו-/LANG=java, /LANG=cs או /LANG=both קובעים את השפה. ב-Linux: מורידים את dsviz-install.zip, פותחים ומריצים את install.sh (שם צריך JDK 17 או 21).

Mac שורה אחת, בלי סיסמה

  1. פותחים את Terminal: Cmd + רווח, כותבים Terminal ולוחצים Enter.
  2. מעתיקים את השורה ומדביקים אותה בחלון של Terminal:
    curl -fsSL https://raw.githubusercontent.com/motiml77/java-lamerhav/master/java-visualizer/installer/mac/install.sh | bash
  3. לוחצים Enter. ההתקנה שואלת באיזו שפה לומדים, ומשם עושה הכול לבד.

לבד מה ההתקנה עושה

  • Java 21 ל-~/Library/Application Support/DSViz, בלי סיסמת מנהל
  • התוסף לכל Eclipse שנמצא (Eclipse עצמו מתקין אותו)
  • התוסף ל-VS Code, VS Code Insiders, VSCodium ו-Cursor
  • התוסף לכל IntelliJ IDEA (2024.2 ומעלה)
  • ב-C#: הספרייה בכל פרויקט, ואם צריך ‎.NET SDK 8
  • תיקיות תרגילים במסמכים
  • עדכון בכניסה למחשב ופעם ביום, ברקע; סביבה שתתקינו אחר כך מקבלת את התוסף לבד

פעם אחת מה עושים אתם

  • מדביקים את השורה ולוחצים Enter
  • בוחרים שפה (או Enter ל-Java)
  • אם Eclipse פתוח: סוגרים אותו (Cmd+Q) ולוחצים Enter
  • בפעם הראשונה macOS שואל אם לתת גישה לתיקיית המסמכים: "אישור"
  • אם מופיעה ההודעה "Background Items Added" (פריט רקע: bash): זה העדכון האוטומטי, לא צריך לעשות כלום

למה שורה ולא קובץ? macOS חוסם קבצים שהורדו בדפדפן כשהם לא חתומים ע"י Apple ("מפתח לא מזוהה"), ואת החסימה אפשר לעקוף רק עם סיסמת מנהל. קבצים ש-curl מוריד לא מסומנים כ"הורדו מהאינטרנט", ולכן אין חסימה ואין שאלה. כל קובץ נבדק מול SHA-256 לפני שהוא מותקן. Apple Silicon ו-Intel, macOS 12 ומעלה.

Eclipse

כל גרסה מ-2020-09 ועד היום, בגרסה ל-Java (Eclipse IDE for Java Developers). ההתקנה ב-Windows או ב-Mac מוצאת אותו לבד, גם כשיש כמה.

לבד

  • התוסף נכנס לכל Eclipse שנמצא, וקידוד UTF-8 מוגדר (עברית תקינה בקוד ובפלט)
  • הספרייה unit4.collectionsLib נוספת לכל פרויקט Java, גם לפרויקט חדש שיוצרים, בלי Build Path
  • חלון "הסברים בעברית" נפתח בצד
  • בכל סגירה של Eclipse נבדק אם יש עדכון

פעם אחת

  • Eclipse סגור בזמן ההתקנה (ההתקנה מציעה לסגור אותו)
  • Eclipse בתיקייה מוגנת (Program Files): מריצים את ההתקנה כמנהל, לחיצה ימנית ← "הפעל כמנהל"

VS Code

אותו תוסף ל-Java ול-C#: הרצה ויזואלית, תרגיל חדש, הוסף מבנה נתונים ושליחת תרגיל, בשורת המצב ובסרגל הצד.

לבד

  • התוסף מותקן ב-VS Code, ב-VS Code Insiders, ב-VSCodium וב-Cursor
  • התוספים של Microsoft (Java או C#) יורדים ברקע, להשלמה אוטומטית וצבעים
  • תיקייה שיש בה קוד שמשתמש ב-Stack, Queue, Node או BinNode של הקורס מקבלת את הספרייה (lib/dsviz.jar) לבד, ברגע שפותחים או שומרים
  • בפעם הראשונה מוצעת תיקיית התרגילים, עם תרגיל לדוגמה

פעם אחת

  • פותחים מחדש את VS Code אחרי ההתקנה
  • התקנתם VS Code אחרי DSViz? ב-Mac התוסף נוסף לבד בבדיקה היומית; ב-Windows מריצים שוב את DSViz-Setup.exe

פרויקט Maven או Gradle לא משתנה לבד: שם מוסיפים את lib/dsviz.jar לתלויות בעצמכם.

Visual Studio (C#)

בוחרים C# במסך השפה של ההתקנה ב-Windows. מאותו רגע, בכל פרויקט C# מסוג קונסול, חדש או קיים, בכל תיקייה:

לבד

  • הפניה ל-Unit4.CollectionsLib, כך ש-Stack, Queue, Node ו-BinNode מוכרים, גם ב-IntelliSense
  • "הרצה ויזואלית" מופיעה בתפריט שליד כפתור ההפעלה הירוק
  • תבנית פרויקט חדשה: "תרגיל מבני נתונים (DSViz)"
  • תיקיית תרגילים מוכנה (DataStructures-CS) עם קיצור בשולחן העבודה

בכל הרצה

  • בוחרים "הרצה ויזואלית" ליד הכפתור הירוק, ולוחצים F5
  • תרגיל חדש, הוסף מבנה נתונים ושליחת תרגיל: מהקיצורים בשולחן העבודה ובתפריט התחל

זה עובד דרך נקודת ההרחבה הרגילה של MSBuild (ImportAfter, ברמת המשתמש), ולכן גם dotnet build ו-Rider מכירים את הספרייה. פרויקט שלא רוצים שייגע בו: <DSVizDisable>true</DSVizDisable> בקובץ ה-csproj.

C# ב-Mac

Visual Studio for Mac הופסק ב-2024, ולכן ב-Mac עובדים ב-C# עם VS Code, עם Rider או עם dotnet בטרמינל. כשבוחרים C# בהתקנה:

  • כל פרויקט C# מכיר את Unit4.CollectionsLib, בלי להוסיף הפניה (אותו קובץ MSBuild כמו ב-Windows).
  • ההרצה הוויזואלית של C# כלולה, ועובדת גם בלי ‎.NET SDK.
  • אם אין ‎.NET SDK, ההתקנה שואלת אם להתקין את גרסה 8 (כ-200 מגה, ל-~/.dotnet, בלי סיסמה). צריך אותו בשביל dotnet build ו-F5 ב-VS Code.

IntelliJ IDEA

IntelliJ IDEA מגרסה 2024.2 ומעלה, Community או Ultimate, בהתקנה רגילה או דרך JetBrains Toolbox. ההתקנה ב-Windows וב-Mac מוצאת כל אחת מהן ומתקינה בה את התוסף בשקט.

לבד

  • התוסף נכנס לכל IntelliJ IDEA שנמצא, גם כשיש כמה
  • כל פרויקט Java מקבל בפתיחה את הספרייה unit4.collectionsLib ו-JDK, גם פרויקט ישן
  • תיקיית התרגילים (DataStructures במסמכים) נפתחת ישר ב-IntelliJ
  • עדכונים: ב-Windows בכניסה למחשב, ב-Mac פעם ביום; ההסרה מוציאה את התוסף

פעם אחת

  • IntelliJ סגור בזמן ההתקנה (ב-Windows ההתקנה מציעה לסגור אותו)
  • פותחים מחדש את IntelliJ

התפריט "מבני נתונים" (אחרי Tools) והחלון DSViz בצד: תרגיל חדש, שליחת תרגיל, הוסף מבנה נתונים, הרצה ויזואלית (Ctrl+Alt+R, או החץ הירוק ליד main), דוגמאות פתורות, הדרכה וכיבוי. ההצעה לפתרון מופיעה רק כמנורה קטנה בשוליים, ליד הפעולות של תרגיל ששלחתם.

בלי התקנה

בדף שאלת בגרות לקוד מעלים את דף השאלה (PDF, Word או צילום) ומקבלים קובצי Java או C# מוכנים: פעולה ריקה לכל סעיף, המחלקות מהשאלה ו-main עם נתונים לדוגמה, ואם רוצים גם הצעה לפתרון. הכול בדפדפן, בלי להתקין כלום. הדף עובר דרך השרת של DSViz ל-Gemini של Google; הפרטים בדף פרטיות.

עדכונים והסרה

עדכונים

  • Windows: בכל כניסה ל-Windows ובכל סגירה של Eclipse נבדק אם יש גרסה חדשה. אם יש, היא יורדת, נבדקת (SHA-256) ומותקנת בשקט עם אותן שפות, אחרי ש-Eclipse נסגר.
  • Mac: בכניסה למחשב ופעם ביום (פריט רקע של המשתמש, בלי סיסמה), וגם כש-VS Code או IntelliJ נפתחים וכש-Eclipse נסגר. סביבת פיתוח שהותקנה אחרי DSViz מקבלת את התוסף באותה בדיקה. היומן: ~/Library/Logs/DSViz/update.log. אפשר גם להריץ שוב את שורת ההתקנה.

הסרה

  • Windows: הגדרות ← אפליקציות ← "מבני נתונים — הרצה ויזואלית" ← הסרה, או "הסרה" בתפריט התחל.
  • Mac: bash ~/Library/Application\ Support/DSViz/uninstall.sh

ההסרה מוציאה את התוספים מכל הסביבות. תיקיות התרגילים במסמכים נשארות, כי יש בהן את העבודה שלכם.

כשמשהו לא עובד

ב-Mac: "macOS לא נתן להתקין את התוסף" ב-Eclipse

ב-macOS 13 ומעלה הטרמינל צריך הרשאה לשנות אפליקציות. הגדרות המערכת ← פרטיות ואבטחה ← ניהול אפליקציות ← מפעילים את Terminal, ומריצים שוב את השורה. או ב-Eclipse: Help ← Install New Software ← Add ← Archive, ובוחרים את ~/Library/Application Support/DSViz/eclipse/dsviz-eclipse-site.zip.

ההתקנה לא מצאה את Eclipse

ב-Windows ההתקנה שואלת איפה הוא נמצא (התיקייה שבה eclipse.exe). ב-Mac: curl -fsSL …/install.sh | DSVIZ_ECLIPSE="/path/Eclipse.app" bash.

ב-VS Code הקוד מסומן באדום: Queue cannot be resolved

שומרים את הקובץ: התוסף מוסיף את הספרייה לתיקייה ברגע שהוא רואה קוד שמשתמש בה. בפרויקט Maven או Gradle מוסיפים את lib/dsviz.jar לתלויות. ואם בתיקייה כבר יש jar אחר של unit4 (המקורי של הבגרות), התוסף לא נוגע בה.

אני רוצה לבדוק שהכול עובד

פותחים את תיקיית התרגילים (DataStructures במסמכים), פותחים את Main.java, ולוחצים "הרצה ויזואלית". אמור להיפתח חלון עם הקוד, המשתנים והמחסנית.
