הורדה התקנה ל-Mac

שאלת בגרות לקוד

מעלים את דף השאלה, ומקבלים קובצי Java מוכנים: פעולה ריקה לכל סעיף, המחלקות שהשאלה מתארת, ו-main שבונה נתונים לדוגמה ומדפיס את התוצאות. ואם נתקעים, יש גם הצעה לפתרון.

גוררים לכאן את דף השאלה או

PDF, Word (docx) או צילום, גם כמה עמודים. אפשר גם להדביק צילום מסך עם Ctrl+V. עד 10 קבצים.
