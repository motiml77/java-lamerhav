תיקיית התרגילים — מבני נתונים עם הרצה ויזואלית
=================================================

התיקייה הזאת הוכנה אוטומטית בהתקנה, ועובדת ב-VS Code, ב-Eclipse וב-IntelliJ IDEA (File ← Open ← התיקייה הזאת).

  src/Main.java     תרגיל לדוגמה
  src/examples/     דוגמאות פתורות (מחסנית, תור, רשימה, עצים)
  lib/dsviz.jar     הספרייה (Stack, Queue, Node, BinNode, Student, Build, Viz)

VS Code:  סמל "מבני נתונים" בסרגל הצד — תרגיל חדש, הוסף מבנה נתונים, הרצה.
Eclipse:  התפריט "מבני נתונים" וכפתורים בסרגל הכלים.
IntelliJ:  התפריט "מבני נתונים", החלון DSViz בצד ימין, ו"הרצה ויזואלית" ליד main.
