מבני נתונים — הרצה ויזואלית

תוסף ל-VS Code ול-Eclipse: בוחרים מבנה נתונים (מחסנית, תור, רשימה מקושרת, עץ), מקבלים תרגיל מוכן עם המבנה, כותבים את הפעולה — ובהרצה נפתח חלון שמראה כל צעד: המבנים, שורת הקוד, מחסנית הקריאות והפלט.

1. מה צריך במחשב

  • Java (JDK) גרסה 8 ומעלה. מומלץ JDK 17 או 21 (למשל Adoptium Temurin).
  • VS Code ו/או Eclipse (גרסה 2020 ומעלה).

2. התקנה

Windows: לחיצה כפולה על install.bat.
Mac / Linux: בטרמינל: ./install.sh

הסקריפט מתקין אוטומטית לכל VS Code ולכל Eclipse שהוא מוצא. אחר כך — לסגור ולפתוח מחדש את התוכנה.

אם Eclipse מותקן במקום לא רגיל: install.bat "C:\path\to\eclipse" (התיקייה שבה נמצא eclipse.exe).

התקנה ידנית (אם הסקריפט לא עבד)

  • VS Code: חלון Extensions ← שלוש הנקודות … למעלה ← Install from VSIX… ← בוחרים את dsviz-1.0.0.vsix. מתקינים גם את Extension Pack for Java.
  • Eclipse: מעתיקים את il.lamerhav.dsviz_1.0.0.jar לתיקייה dropins שבתוך תיקיית Eclipse, ומפעילים מחדש.

3. שימוש

VS Code

  1. פותחים תיקייה לתרגילים (File ← Open Folder). אפשר גם תיקייה ריקה.
  2. לוחצים על הסמל מבני נתונים בסרגל הצד, ובוחרים מבנה: מחסנית / תור / רשימה מקושרת / עץ.
  3. עונים על כמה שאלות קצרות (טיפוס, מה הפעולה מחזירה, ערכים) — ונפתח קובץ תרגיל מוכן.
  4. כותבים את הפעולה ולוחצים ▶ הרצה ויזואלית (למעלה מימין, בשורת המצב, או Ctrl+Alt+R).

Eclipse

  1. בתפריט העליון: מבני נתונים ← תרגיל חדש: מחסנית… (או הכפתור תרגיל חדש בסרגל הכלים).
  2. בחלון שנפתח בוחרים מבנה, טיפוס ומה הפעולה מחזירה — ורואים מיד את הקוד שייווצר. אם אין פרויקט מתאים, ייווצר פרויקט חדש בשם DataStructures.
  3. כותבים את הפעולה ולוחצים הרצה ויזואלית (בסרגל הכלים, או לחיצה ימנית בקוד).

4. בחלון ההרצה

  • ← / רווח — הצעד הבא, → — הצעד הקודם, P — הפעלה אוטומטית.
  • ירוק = נוסף, צהוב = נקרא, כתום = שונה, אדום מקווקו = הוצא.
  • בתפריט דוגמאות פתורות יש דוגמאות לכל מבנה.
