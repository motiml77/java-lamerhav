מבני נתונים — הרצה ויזואלית

תוסף ל-VS Code ול-Eclipse: בוחרים מבנה נתונים (מחסנית, תור, רשימה מקושרת, עץ, מערך, מערך דו-ממדי — של מספרים, מחרוזות או תלמידים), מקבלים תרגיל מוכן עם המבנה, כותבים את הפעולה — ובהרצה נפתח חלון שמראה כל צעד: המבנים, שורת הקוד, המשתנים, מעקב הרקורסיה והפלט.

1. מה צריך במחשב

  • Windows: Java כלולה בהתקנה — לא צריך להוריד כלום. Mac/Linux: JDK 17 או 21 (למשל Adoptium Temurin).
  • VS Code ו/או Eclipse (גרסה 2020 ומעלה).

2. התקנה

Windows: לחיצה כפולה על DSViz-Setup.exe ← הבא ← בוחרים שפה (Java, C#, או שתיהן) ← התקן ← סיום.
Mac: לחיצה כפולה על install-mac.command.   Linux: בטרמינל: ./install.sh

ההתקנה מוצאת לבד את VS Code ואת כל ההתקנות של Eclipse במחשב ומתקינה בכולן, ויוצרת תיקיית תרגילים מוכנה במסמכים (DataStructures) עם קיצור דרך בשולחן העבודה. בהפעלה הראשונה Eclipse מכין את עצמו לבד (פרויקט, קידוד עברית, תרגיל פתוח). אחר כך — לסגור ולפתוח מחדש את התוכנה.

את התוספים של Microsoft ל-VS Code (השלמה אוטומטית ל-Java / ל-C#) ההתקנה מורידה לבד ברקע — צריך לשם כך אינטרנט, אבל בלעדיו ההרצה עובדת רגיל.

C# (Visual Studio / VS Code / Rider): החבילה כוללת את כל מה שצריך להרצה הוויזואלית (בלי להתקין שום דבר נוסף). פותחים את הקיצור תרגילי C# בשולחן העבודה (פתרון של Visual Studio עם תרגיל ודוגמאות), ובתפריט שליד כפתור ההפעלה הירוק בוחרים הרצה ויזואלית. ב-VS Code: אותו תוסף, "הרצה ויזואלית" על קובץ ‎.cs. ב-Rider / שורת פקודה: %LOCALAPPDATA%\DSViz\cs\dsviz-cs.exe <תיקיית הפרויקט>.

פרויקט C# אחר (שלכם, או שהמורה שלחה) ב-Visual Studio: לא צריך להריץ שום דבר משורת הפקודה. בכל פרויקט C# — חדש או קיים, בכל תיקייה — מופיעה לבד האפשרות הרצה ויזואלית ליד כפתור ההפעלה, ואפשר לכתוב using Unit4.CollectionsLib; בלי להוסיף הפניה בעצמכם. (אם הפרויקט היה פתוח ב-Visual Studio לפני ההתקנה — סוגרים ופותחים אותו מחדש פעם אחת.)

אם Windows מציג "Windows protected your PC" — זו הגנה כללית על קובץ חדש ולא חתום. לוחצים More info ← Run anyway.

אם לא נמצא לא VS Code ולא Eclipse — ההתקנה תשאל איפה Eclipse. אם אין הרשאה לכתוב לתיקייה שלו (למשל ב-Program Files) — לחיצה ימנית על DSViz-Setup.exe ← "הפעל כמנהל".

למעבדת מחשבים: DSViz-Setup.exe /S /LANG=java (או cs / both) מתקין בלי שאלות. הסרה: דרך "אפליקציות ותכונות" של Windows.

התקנה ידנית (אם הסקריפט לא עבד)

  • VS Code: חלון Extensions ← שלוש הנקודות … למעלה ← Install from VSIX… ← בוחרים את dsviz-1.0.1.vsix. מתקינים גם את Extension Pack for Java.
  • Eclipse: מעתיקים את il.lamerhav.dsviz_1.0.1.jar לתיקייה dropins שבתוך תיקיית Eclipse, ומפעילים מחדש.

3. שימוש

VS Code

  1. פותחים תיקייה לתרגילים (File ← Open Folder). אפשר גם תיקייה ריקה.
  2. לוחצים על הסמל מבני נתונים בסרגל הצד. ב"תרגיל חדש" בוחרים מבנה: מחסנית / תור / רשימה מקושרת / עץ / מערך.
    ב"הוספה לקוד" — צור תור, צור מערך, צור תלמיד... נכנס לקוד במקום הסמן, עם נתוני דמה.
  3. עונים על כמה שאלות קצרות (טיפוס, מה הפעולה מחזירה, ערכים) — ונפתח קובץ תרגיל מוכן.
  4. כותבים את הפעולה ולוחצים ▶ הרצה ויזואלית (למעלה מימין, בשורת המצב, או Ctrl+Alt+R), — החלון מראה כל שורה בקוד. (הרצה רגילה, Run, מדפיסה רק לקונסול.)

Eclipse

  1. בתפריט העליון: מבני נתונים ← תרגיל חדש: מחסנית… (או הכפתור תרגיל חדש בסרגל הכלים).
    הכפתור הוספה לקוד (או לחיצה ימנית בקוד): צור תור / מחסנית / מערך / תלמיד עם נתוני דמה.
  2. בחלון שנפתח בוחרים מבנה, טיפוס ומה הפעולה מחזירה — ולוחצים יצירת התרגיל. אם אין פרויקט מתאים, ייווצר פרויקט חדש בשם DataStructures.
  3. כותבים את הפעולה ולוחצים הרצה ויזואלית (בסרגל הכלים, או לחיצה ימנית בקוד).

4. בחלון ההרצה

  • ← / רווח — הצעד הבא, → — הצעד הקודם, P — הפעלה אוטומטית.
  • ירוק = נוסף, צהוב = נקרא, כתום = שונה, אדום מקווקו = הוצא.
  • כל שורה: השורה הנוכחית מודגשת בקוד, טבלת המשתנים מראה את כל הערכים (מה שהשתנה — בצהוב), ושמות המשתנים (p, prev, temp) מופיעים מעל החוליות והמבנים.
  • בתפריט דוגמאות פתורות יש דוגמאות לכל מבנה.
