# מבני נתונים — הרצה ויזואלית

תרגילי **מחסנית, תור, רשימה מקושרת ועצים** (ה-API של ספריית הבגרות `unit4.collectionsLib`)
עם **תצוגה ויזואלית של כל צעד** בהרצה.

1. לוחצים על הסמל **מבני נתונים** בסרגל הצד ובוחרים מבנה (מחסנית / תור / רשימה / עץ / מערך / מערך דו-ממדי, גם של `Student`).
   או **הוסף מבנה נתונים** (כפתור בשורת המצב, Ctrl+Alt+I): בוחרים מבנה, ערכים (או אקראיים) ושם, רואים ציור של המבנה — והוא נכנס לקוד במקום הסמן.
2. עונים על כמה שאלות (טיפוס, מה הפעולה מחזירה, ערכים) — ונפתח תרגיל מוכן עם המבנה.
3. כותבים את הפעולה ולוחצים **הרצה ויזואלית** (הכפתור הירוק למעלה מימין, בשורת המצב, או Ctrl+Alt+R) —
   כל שורה בקוד היא צעד, עם המשתנים. הרצה רגילה (Run) מדפיסה רק לקונסול.

התוסף מקמפל ומריץ בעצמו (javac + java בטרמינל) — לא צריך את Extension Pack for Java בשביל להריץ.
Java: זו שהותקנה עם תוכנית ההתקנה של מבני נתונים, או JAVA_HOME, או java שב-PATH (או ההגדרה dsviz.javaHome).

**גם C#:** בתיקייה של פרויקט C# (או כשבוחרים C# בשאלה "באיזו שפה?") אותו תוסף יוצר תרגיל חדש כפרויקט (`Exercises\<שם>`),
מוסיף קטעי קוד עם נתוני דמה, ומריץ **הרצה ויזואלית** על קובץ ‎.cs — בעזרת `dsviz-cs` שמותקן בחבילת ה-C# של תוכנית ההתקנה
(הגדרות: `dsviz.language`, `dsviz.csRunner`). לא צריך להתקין ‎.NET — dsviz-cs כולל אותו.
