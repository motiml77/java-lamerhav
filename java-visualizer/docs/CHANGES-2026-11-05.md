# DSViz — מה השתנה בגרסה הזו (5.11.2026)

רשימת התיקונים והשיפורים שנכנסו.

**מאגר התרגילים ומסך הכניסה** כבר לא גרסת מעבדה: הם חלק מ-DSViz-Setup.exe (הקישור הקבוע) ומהעדכון האוטומטי, ב-Eclipse, ב-IntelliJ IDEA וב-Visual Studio (C#). מי שהתקין דרך DSViz-Lab-Setup.exe מקבל עדכון רגיל — בלי כפילות ובלי שהמאגר נמחק.

## חלון ההרצה הוויזואלית (Eclipse, IntelliJ, Visual Studio — אותו חלון)
- פריסה חדשה: הקוד משמאל לכל הגובה, התצוגה הוויזואלית מימין, והפלט והמשתנים למטה.
- כפתורי הגדלה / הקטנה (zoom) לכל חלק בנפרד: הקוד, התצוגה, המשתנים והפלט.
- אפשר לשנות את הגודל של כל החלקים בגרירה.
- "הרצה גם של main" דלוק כברירת מחדל, ונשאר כבוי רק אם המשתמש כיבה אותו.
- כרטיס הלולאה: תג "i = N" וציר דק עם הערכים בקצוות, במקום שורת תיבות שנראית כמו מערך.
- כל הציורים (מבנים, תנאים, קריאות, קלט, רקורסיה, מעקב משתנים) מגיבים להגדלה / הקטנה.

## Eclipse
- פרויקט עם `module-info.java`: הספרייה נכנסת כמודול (module path + `requires dsviz;`) — נעלמת השגיאה
  "The package unit4.collectionsLib is not accessible", גם בפרויקט חדש וגם בפרויקט שכבר שבור.
  נבדק ב-Eclipse אמיתי (פרויקט חדש, פרויקט שבור, הרצה ויזואלית).
- סמל המנורה של "הצעה לפתרון": כפתור עם סמל מצויר במקום אמוג'י (שיצא כריבוע ריק ב-Windows).

## IntelliJ IDEA
- ספריית הקורס נוספת אוטומטית לפרויקט חדש (בעבר תיקיית התוסף לא נמצאה והבנייה נכשלה). נבדק ב-IntelliJ אמיתי.
- בלי שגיאות "Slow operations on EDT" בהוספת הספרייה ובהרצה הוויזואלית.
- אין עוד אמוג'י (ריבוע ריק) בכותרת חלון "הצעה לפתרון" ובהודעה אחרי יצירת תרגיל.

## Visual Studio (C#)
- הרצה ויזואלית: נתיב עם מרכאה בסוף לא מפיל עוד את dsviz-cs, ופרופיל ישן מתוקן לבד.
- סרגל כלים עצמאי של DSViz בראש Visual Studio (שורה משלו): תרגיל חדש, הוספת מבנה נתונים, שליחת תרגיל, הרצה ויזואלית, הדרכה.
  מותקן אוטומטית בכל Visual Studio שנמצא במחשב. אם ההרחבה לא נטענת — הכפתורים נשארים בתפריט ההפעלה ליד הכפתור הירוק.
- "הצעה לפתרון" לא כפתור: היא מופיעה בתוך הקוד, ליד הפעולה.
- C#: הפעולות size / duplicate של הספרייה לא נרשמות עוד כצעדים בהרצה הוויזואלית.

## ההתקנה (Windows)
- אין יותר קיצורי דרך בשולחן העבודה (נשארים קיצורי תפריט התחלה).
- התקנה על קיימת מנקה את הקודם: קיצורים ישנים, קבצים ותיקיות מגרסה קודמת, ההרחבה של Visual Studio.
- בסוף ההתקנה אין חלון cmd: ההורדות והתקנת התוספים רצות מאחורי הקלעים, וההתקנה מחכה שיסתיימו.
